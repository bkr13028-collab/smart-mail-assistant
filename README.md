# 스마트 메일 비서 (1차 시제품)

휴대폰·PC 반응형 Gmail 4계정 통합 메일 뷰어입니다.

## 사용 방법
1. `index.html`을 정적 HTTPS 호스팅(Netlify 등)에 올립니다. 파일을 직접 열면 Google OAuth가 작동하지 않습니다.
2. Google Cloud Console에서 프로젝트를 만들고 **Gmail API**를 사용 설정합니다.
3. OAuth 동의 화면을 구성합니다. 테스트 모드에서는 각 Gmail 계정을 테스트 사용자로 등록해야 합니다.
4. OAuth 클라이언트 유형 **웹 애플리케이션**을 생성하고 Netlify 사이트의 정확한 `https://...netlify.app` 주소를 **승인된 JavaScript 원본**에 등록합니다.
5. 사이트의 `Google OAuth 설정`에 클라이언트 ID를 입력하고 저장합니다.
6. `Gmail 연결`을 4회 눌러 각 계정에 읽기 전용 권한을 승인합니다. 계정이 중복되면 기존 연결을 갱신합니다.

## 현재 구현
- 최대 4계정 연결, 계정별 받은편지함 최근 40건 읽기
- 통합 목록, 검색, 중요도 필터, 규칙 기반 중요도 판별 및 짧은 미리보기
- 외국어 원문을 Google 번역으로 여는 링크
- 예시 데이터로 즉시 UI 확인
- 메일 읽기 전용 (`gmail.readonly`), 토큰은 메모리에만 보관

## 아직 필요한 기능
- 진정한 AI 요약과 자동 한국어 번역: 인증된 백엔드 및 번역/AI API가 필요합니다.
- 안전한 다중 계정 자동 재로그인: 백엔드 OAuth authorization code flow, 암호화된 토큰 저장소 필요.
- 새 메일 푸시 알림, 답장, 처리 완료 기록, 장기 데이터 동기화.
- 현재 중요도 분류는 키워드 기반이며 오분류할 수 있습니다. 결제·보안 관련 메일은 반드시 원문을 확인하세요.

## 개인정보
OAuth 클라이언트 ID만 브라우저 localStorage에 저장합니다. 이메일 본문과 접근 토큰은 앱 자체 서버에 저장하지 않습니다. Google 번역 링크를 누르면 해당 메일 내용이 외부 번역 서비스로 전달될 수 있으므로 민감한 메일은 사용에 주의하세요.

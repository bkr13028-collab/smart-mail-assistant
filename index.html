Google OAuth 설정

Google Cloud에서 Gmail API 활성화 후 OAuth 웹 클라이언트 ID를 발급하고, 현재 사이트 주소를 승인된 JavaScript 원본에 등록하세요. localhost 또는 HTTPS에서 실행해야 합니다.

클라이언트 ID는 이 브라우저에만 저장합니다. 메일과 접근 토큰은 서버로 전송하거나 영구 저장하지 않습니다.
